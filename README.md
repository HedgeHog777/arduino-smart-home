# Arduino Smart Home

Bachelor's thesis project.

A prototype Smart Home system developed using Arduino.

## Overview

This project demonstrates the implementation of a modular smart home system capable of monitoring sensors and controlling household devices.

The system was developed as part of my Bachelor's degree.

- Sensor monitoring
- Lighting control
- Automation
- Microcontroller communication
